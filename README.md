# 看見指數就往前衝的人，開始談速限：奧特曼在史丹佛商學院（導讀）

Stanford GSB〈View From The Top〉訪談（2026-10-21 上傳，48:48）：OpenAI 執行長 Sam Altman 說最難的決定是 AI 該多快變聰明；對齊比預期容易，讓他擔心別人因此過度自信；他希望 AI 帶來的是文藝復興，而不是工業革命。

**線上閱讀：** https://lushinshang.github.io/sam-altman-staying-human-superintelligence/

## 200字介紹

OpenAI 執行長 Sam Altman 在史丹佛商學院說，現在最難的決定是「暫停、控速、智慧速限」：他認為可解，但要時間，也要世界一起同意怎麼訂，誰來訂、量什麼，訪談沒有說。對齊到目前比預期容易，他卻因此擔心有些團隊過度自信，太敢往前衝。資安、開源門檻、數學界的反應、職涯建議與「文藝復興而非工業革命」，導讀逐項對照官方資料，標出哪些是他的自述、哪些查得到。提問學生的姓名與個人背景不寫入。
